# 設計書

## どんなアプリか

ふつうに使える電卓に、便利機能とゲームが付いたアプリ。

一覧でモードを選ぶと、そのモードの電卓が出る。

- **割り勘モード**（便利機能）：飲み会の合計を計算して、1 人いくらかを出し、記録しておける
- **いたずらモード**（ゲーム）：計算によって画面がおかしくなる。777 を計算するとスロットが始まる
- 演出を見つけると**実績**が開放され、マイページで確認できる

## ページ

| ページ | URL | ファイル | 周 |
| --- | --- | --- | --- |
| ログイン | — | `src/pages/login/LoginPage.jsx` | できている |
| 一覧 | `/` | `src/pages/home/HomePage.jsx` | 1 周目 |
| ノーマル電卓 | `/calculator` | `src/pages/calculator/CalculatorPage.jsx` | 1 周目 |
| マイページ | `/mypage` | `src/pages/mypage/MyPage.jsx` | 1 周目 |
| 割り勘 | `/warikan` | `src/pages/warikan/WarikanPage.jsx` | 2 周目 |
| いたずら電卓 | `/prank` | `src/pages/prank/PrankPage.jsx` | 2 周目 |
| スロット | `/slot` | `src/pages/slot/SlotPage.jsx` | 2 周目 |

1 周目の 3 ページは、ノーマル電卓が全モードの土台になる。2 周目はノーマル電卓ができてから始める。

## データの形

### `achievements`（実績）

| フィールド | 型 | 中身 |
| --- | --- | --- |
| `uid` | 文字列 | 実績を開放した人 |
| `userName` | 文字列 | 開放した人の名前 |
| `name` | 文字列 | 実績の名前（下の表のどれか） |
| `createdAt` | 数値 | 開放した日時（`Date.now()`） |

同じ人が同じ実績を 2 回保存しないように、保存する前に `uid` と `name` で探し、見つかったら保存しない。

実績の名前は次の 6 つ。**1 文字も変えずにこのとおり使う**（マイページはこの名前で表示する）。

| 名前 | 開放する条件 | 保存するページ |
| --- | --- | --- |
| `ふるえる数字` | 割り切れない割り算をする | いたずら電卓 |
| `ふくらむ数字` | 足し算の答えが 100 以上になる | いたずら電卓 |
| `こおる画面` | 引き算の答えがマイナスになる | いたずら電卓 |
| `暴走するエラー` | 0 で割る | いたずら電卓 |
| `777` | 答えが 777 になる | いたずら電卓 |
| `大当たり` | スロットで 3 つそろう | スロット |

### `warikans`（割り勘の記録）

| フィールド | 型 | 中身 |
| --- | --- | --- |
| `uid` | 文字列 | 記録した人 |
| `userName` | 文字列 | 記録した人の名前 |
| `title` | 文字列 | 飲み会の名前（例：サークルの新歓） |
| `total` | 数値 | 合計金額 |
| `people` | 数値 | 人数 |
| `perPerson` | 数値 | 1 人あたりの金額（1 円単位で切り上げ） |
| `paid` | 真偽値 | 精算が済んだか。最初は `false` |
| `createdAt` | 数値 | 記録した日時（`Date.now()`） |

### どのページが何を使うか

| ページ | `achievements` | `warikans` |
| --- | --- | --- |
| マイページ | 読む | — |
| 割り勘 | — | 作る・読む・直す・消す |
| いたずら電卓 | 作る | — |
| スロット | 作る | — |

読むときは、どれも**自分の分だけ**（`uid` が自分のもの）を新しい順に読む。

## 電卓の決まり

- 電卓のあるページは、**ノーマル電卓のコードを自分のページにコピーして改造する**。ほかの人のページのファイルは書き換えない
- 計算は「1 つ目の数」「演算子」「2 つ目の数」を state に持って行う。`eval` は使わない

## 各ページ

### 一覧

- 各モード（ノーマル電卓・割り勘・いたずら電卓）への入口を並べる。それぞれ名前と 1 行の説明を出す
- マイページへのリンクと、ログアウトのボタンを置く
- 2 周目のページはまだないので、入口を押すと何も表示されない状態でよい

### ノーマル電卓

- 画面に表示欄と、ボタン（`0`〜`9`・`+`・`-`・`×`・`÷`・`=`・`C`）を置く
- 数字を押すと表示欄に数字が足される。演算子を押してから次の数字を打ち、`=` で答えが出る
- `C` で全部消える
- `=` のあと、続けて演算子を押すと、答えを 1 つ目の数として計算を続けられる
- 小数点のボタンは作らない。割り算の答えが小数になるのはそのまま表示してよい
- 一覧に戻るリンクを置く

### マイページ

- ログインしている人の名前を出す
- 自分が開放した実績を、新しい順に、名前と開放した日時で並べる
- 実績がないときは「まだ実績がありません」と出す
- 一覧に戻るリンクを置く
- 1 周目のうちは実績を保存するページがないので、Firebase のコンソールで手で 1 件入れて確かめる

### 割り勘

- 上半分はノーマル電卓。飲み会の合計を計算する
- 下に「飲み会の名前」「人数」の入力欄と「割り勘する」ボタンを置く
- ボタンを押すと、電卓の答えを合計として 1 人あたりの金額を出し、`warikans` に保存する
- その下に、自分の記録を新しい順に並べる（名前・合計・人数・1 人あたり・日時）
- 記録ごとに「精算済みにする」ボタン（`paid` を `true` にする）と「削除」ボタンを置く。精算済みの記録は薄く表示する

### いたずら電卓

- ノーマル電卓をコピーして、`=` を押したときの答えによって演出を出す
  - 割り切れない割り算 → 答えが小刻みに震える
  - 足し算で 100 以上 → 答えの文字が大きくふくらむ
  - 引き算でマイナス → 画面が青くなる
  - 0 で割る → 「エラー」が画面いっぱいに点滅する
  - 答えが 777 → スロットのページに移る
- 演出が出たら、その実績を保存する（もう持っていれば保存しない）
- 演出は CSS のクラスを付け外しして出す。`C` を押すと元に戻る

### スロット

- 数字が 3 つ並ぶ。「回す」ボタンを押すと、それぞれ 1〜9 のどれかになる
- 3 つそろったら「大当たり」と出し、実績を保存する（もう持っていれば保存しない）
- いたずら電卓に戻るリンクを置く
