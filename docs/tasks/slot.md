# スロット

ファイル：`src/pages/slot/SlotPage.jsx`
ブランチ：`slot`

## 作るもの

- 数字が 3 つ並ぶ
- 「回す」ボタンを押すと、3 つの数字がそれぞれ 1〜9 のどれかになる
- 3 つそろったら「大当たり」と出て、実績「大当たり」を保存する（もう持っていれば保存しない）
- いたずら電卓に戻るリンクがある

使うデータ：

| コレクション | フィールド |
| --- | --- |
| `achievements` | `uid`・`userName`・`name`（実績の名前）・`createdAt` |

2 周目のページだが、スロットは電卓のコードを使わないので、電卓の修正を待たずに始めてよい。ただしステップ 4（保存）は、Firestore のセキュリティルールが設定されるまで動かない。ルールはあさひが設定するので、ステップ 3 まで進めて待つ。

## 手順

### ステップ 1：数字を 3 つ並べる

「`numbers` という state を作る。最初は `[1, 2, 3]`」

「`numbers` の 3 つの数字を横に並べて出す。その下に『回す』ボタンを置く」

- `1` `2` `3` が横に並び、その下に「回す」ボタンが出れば OK。ボタンはまだ押しても何も起きない

### ステップ 2：「回す」で数字を変える

「`spin` という関数を作る。中身は、1〜9 のどれかの数を 3 つ作って、`numbers` に入れる」

「『回す』を押したら `spin` を呼ぶ」

- 押すたびに、3 つの数字がばらばらに変われば OK
- 何回押しても、0 や 10 が出なければ OK

### ステップ 3：そろったら「大当たり」と出す

「`message` という state を作る。最初は空の文字 `""`」

「`spin` を直す。3 つの数字が全部同じなら `message` を『大当たり』に、そうでなければ空にする」

「数字の下に `message` を出す」

- 3 つそろったときだけ「大当たり」と出れば OK
- そろわなかったら、前の「大当たり」が消えれば OK

1〜9 だと、そろうのは 81 回に 1 回くらい。確かめるときは、いったん 1〜2 のどれかにして確かめ、終わったら 1〜9 に戻す。

### ステップ 4：実績を保存する

「`saveAchievement` という関数を作る。中身は、`achievements` コレクションから `uid` が自分のもので、`name` が `大当たり` のものを探す。見つからなければ、次の中身で `achievements` に 1 件保存する」

| フィールド | 値 |
| --- | --- |
| `uid` | 自分の UID |
| `userName` | 自分の名前 |
| `name` | `大当たり` |
| `createdAt` | `Date.now()` |

「`spin` を直す。3 つそろったら `saveAchievement` を呼ぶ」

実績の名前は `大当たり`。設計書のとおり、1 文字も変えずに使う（マイページはこの名前で表示する）。

- そろったあと、Firebase のコンソールの `achievements` に「大当たり」が 1 件増えていれば OK
- もう一度そろえても、件数が増えなければ OK
- マイページを開くと「大当たり」が出れば OK
- 参考：書き方の見本「自分のものだけ取ってくる」、レシピ「読む」「作る」

### ステップ 5：いたずら電卓に戻るリンクを置く

「いたずら電卓（`/prank`）に戻るリンクを置く」

- 押すと「いたずら電卓」の見出しのページに移れば OK
- 参考：書き方の見本「ページの移動」

### ステップ 6：見た目を整える

「3 つの数字を大きな文字にして、1 つずつ枠で囲む。『大当たり』は目立つ色にする」

- スロットらしい見た目になれば OK
- 参考：書き方の見本「CSS」
