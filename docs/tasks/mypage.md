# マイページ

ファイル：`src/pages/mypage/MyPage.jsx`
ブランチ：`mypage`

## 作るもの

- ログインしている人の名前が出る
- 自分が開放した実績が、新しい順に、名前と開放した日時で並ぶ
- 実績がないときは「まだ実績がありません」と出る
- 一覧に戻るリンクがある

使うデータ：

| コレクション | フィールド |
| --- | --- |
| `achievements` | `uid`・`userName`・`name`（実績の名前）・`createdAt` |

実績を保存するページ（いたずら電卓・スロット）は 2 周目に作る。それまでは、Firebase のコンソールで手で入れたデータで確かめる。

## 手順

### ステップ 1：名前を出す

「ログインしている人の名前を『〇〇 さんのマイページ』と出す」

- 自分の Google アカウントの名前が出れば OK

### ステップ 2：確かめ用の実績を手で入れる

Firebase のコンソールで、`achievements` コレクションにドキュメントを 1 件足す。フィールドは次のとおり。

| フィールド | 型 | 値 |
| --- | --- | --- |
| `uid` | string | 自分の UID（コンソールの Authentication の画面でコピーする） |
| `userName` | string | 自分の名前 |
| `name` | string | `ふるえる数字` |
| `createdAt` | number | `1763450000000` |

- コンソールの `achievements` に 1 件入っていれば OK

### ステップ 3：自分の実績を取ってくる

「`achievements` という state を作る。最初は空の配列」

「`getAchievements` という関数を作る。中身は、`achievements` コレクションから `uid` が自分のものを新しい順に取得して、`achievements` を更新する」

「画面が表示されたときに 1 回だけ、`getAchievements` を呼ぶ」

- 最初はブラウザのコンソールにエラーが出る。エラーの中のリンクを開いて「インデックスを作成」を押し、数分待つ
- 参考：書き方の見本「自分のものだけ取ってくる」、レシピ「読む」

### ステップ 4：実績を並べる

「`achievements` を 1 件ずつ、実績の名前と開放した日時を表示する」

- ステップ 2 で入れた「ふるえる数字」が、日時と一緒に出れば OK
- コンソールでもう 1 件（`name` は `777`、`createdAt` は `1763460000000`）足して再読み込みすると、`777` が上に出れば OK
- 参考：書き方の見本「一覧と出し分け」「日時の表示」

### ステップ 5：実績がないときの表示

「`achievements` が 0 件なら『まだ実績がありません』と出す」

- コンソールで自分の実績を全部消して再読み込みすると、「まだ実績がありません」と出れば OK
- 参考：書き方の見本「一覧と出し分け」

### ステップ 6：一覧に戻るリンクを置く

「一覧（`/`）に戻るリンクを置く」

- 押すと一覧に戻れば OK
- 参考：書き方の見本「ページの移動」
