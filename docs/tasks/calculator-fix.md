# ノーマル電卓の修正

ファイル：`src/pages/calculator/CalculatorPage.jsx`・`src/pages/calculator/CalculatorPage.css`・`src/App.jsx`
ブランチ：`calculator-fix`

## 作るもの

1 周目の電卓（PR #1）は計算は正しく動くが、担当シートとずれているところが残っている。2 周目に割り勘といたずら電卓の 2 人がこのコードをコピーして改造するので、その前に直す。

- 見出しが「ノーマル電卓」になる
- state と関数の名前が、`docs/tasks/calculator.md` と同じになる
- ボタンが 4 列に並ぶ
- 一覧に戻るリンクがある

使うデータ：なし

計算の動き（四則演算・`=` のあとの続き・`C`・0 で割ったときのメッセージ）は今のままでよい。変えないこと。

## 手順

### ステップ 1：見出しを直す

「見出しを『おもしろ電卓』から『ノーマル電卓』に直す」

- 一覧で「ノーマル電卓」を押すと、「ノーマル電卓」の見出しのページに移れば OK

### ステップ 2：重なっているルートを消す

「`src/App.jsx` で `/calculator` の `Route` が 2 行あるので、下の 1 行を消す」

- `src/App.jsx` の中に `path="/calculator"` が 1 つだけになっていれば OK
- 一覧から電卓に移れれば OK

### ステップ 3：名前を担当シートにそろえる

「state と関数の名前を、次のとおりに変える」

| 今の名前 | 新しい名前 |
| --- | --- |
| `a` / `setA` | `first` / `setFirst` |
| `op` / `setOp` | `operator` / `setOperator` |
| `b` / `setB` | `second` / `setSecond` |
| `pressNumber` | `pushNumber` |
| `pressOperator` | `pushOperator` |
| `pressEqual` | `calculate` |
| `pressClear` | `clear` |

`message` はそのままでよい。

- `12 + 3 =` で `15`、続けて `× 2 =` で `30` と出れば OK
- `5 ÷ 0 =` で「0では割れません」と出れば OK
- `C` で表示欄が `0` に戻れば OK

### ステップ 4：使っていない部品を消す

「`CalcButton.jsx` と `CalcButton.css` を消す」

今の電卓はこの部品を使っていない。2 周目にコピーするファイルを 1 つにしておくため、消す。

- 2 つのファイルが消えていて、電卓がこれまでどおり動けば OK

### ステップ 5：ボタンを 4 列に並べる

「ボタンを次の順に並べる。ボタンを囲む `div` を作り、CSS の grid で 4 列にする」

```
7  8  9  ÷
4  5  6  ×
1  2  3  -
0  C  =  +
```

「演算子のボタンと `=`・`C` は、数字のボタンと色を変える」

- 上の表のとおり、4 列 4 行に並んでいれば OK
- 数字と演算子が色で見分けられれば OK
- 参考：書き方の見本「CSS」

### ステップ 6：一覧に戻るリンクを置く

「一覧（`/`）に戻るリンクを置く」

- 押すと一覧に戻れば OK
- 参考：書き方の見本「ページの移動」
