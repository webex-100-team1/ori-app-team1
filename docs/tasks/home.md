# 一覧

ファイル：`src/pages/home/HomePage.jsx`
ブランチ：`home`

## 作るもの

- 各モード（ノーマル電卓・割り勘・いたずら電卓）への入口が並ぶ。それぞれに名前と 1 行の説明が出る
- 入口を押すと、そのモードのページに移る
- マイページへのリンクと、ログアウトのボタンがある

使うデータ：なし

## 手順

### ステップ 1：モードの入口を並べる

「見出しを『電卓アプリ』にする」

「ノーマル電卓（`/calculator`）・割り勘（`/warikan`）・いたずら電卓（`/prank`）へのリンクを並べる。それぞれ、名前と 1 行の説明を出す」

- 「ノーマル電卓」を押すと、「ノーマル電卓」の見出しのページに移れば OK
- 割り勘・いたずら電卓も同じように移れば OK
- 参考：書き方の見本「ページの移動」

### ステップ 2：マイページへのリンクを置く

「名前の横に、マイページ（`/mypage`）へのリンクを置く」

- 押すと「マイページ」の見出しのページに移れば OK

### ステップ 3：見た目を整える

「入口を 1 つずつ枠で囲んで、カードのように並べる」

- 3 つの入口が、それぞれ枠に囲まれて並んでいれば OK
- 参考：書き方の見本「CSS」
