# ノーマル電卓

ファイル：`src/pages/calculator/CalculatorPage.jsx`
ブランチ：`calculator`

## 作るもの

- 表示欄と、ボタン（`0`〜`9`・`+`・`-`・`×`・`÷`・`=`・`C`）がある
- 数字と演算子を押して `=` を押すと、答えが出る
- 答えが出たあと、続けて演算子を押すと、答えを使って計算を続けられる
- `C` で全部消える

使うデータ：なし

このページは、割り勘といたずら電卓の土台になる（2 人がこのコードをコピーして改造する）。設計書の「電卓の決まり」のとおり、計算は state を 3 つ使って行い、`eval` は使わない。

## 手順

### ステップ 1：表示欄とボタンを置く

「表示欄と、`0`〜`9`・`+`・`-`・`×`・`÷`・`=`・`C` のボタンを置く」

- 表示欄とボタンが全部画面に出れば OK。ボタンはまだ押しても何も起きない

### ステップ 2：数字を押したら表示する

「`first` という state を作る。最初は空の文字 `""`」

「`pushNumber` という関数を作る。中身は、押された数字を `first` の後ろに足す」

「数字のボタンを押したら、その数字を渡して `pushNumber` を呼ぶ。表示欄には `first` を出す」

- `1`・`2`・`3` と押すと、表示欄に `123` と出れば OK

### ステップ 3：演算子と 2 つ目の数を入れる

「`operator` と `second` という state を作る。どちらも最初は空の文字 `""`」

「`pushOperator` という関数を作る。中身は、`first` が空でなければ、押された演算子を `operator` に入れる」

「`pushNumber` を直す。`operator` が空なら `first` の後ろに、空でなければ `second` の後ろに数字を足す」

「表示欄には、`first`・`operator`・`second` を並べて出す」

- `1`・`2`・`+`・`3` と押すと、表示欄に `12 + 3` と出れば OK
- 何も押していないときに `+` を押しても、何も起きなければ OK

### ステップ 4：`=` で計算する

「`calculate` という関数を作る。中身は、`second` が空でなければ、`first` と `second` を数にして `operator` のとおりに計算し、答えを `first` に入れて、`operator` と `second` を空にする」

「`=` を押したら `calculate` を呼ぶ」

- `12 + 3 =` で `15`、`12 - 3 =` で `9`、`12 × 3 =` で `36`、`12 ÷ 3 =` で `4` と出れば OK
- `15` が出たあと `× 2 =` と押すと、`30` と出れば OK
- `12 +` まで押して `=` を押しても、何も起きなければ OK

### ステップ 5：`C` で消す

「`clear` という関数を作る。中身は、`first`・`operator`・`second` を全部空にする」

「`C` を押したら `clear` を呼ぶ」

- 計算の途中でも答えが出たあとでも、`C` を押すと表示欄が空になれば OK

### ステップ 6：一覧に戻るリンクを置く

「一覧（`/`）に戻るリンクを置く」

- 押すと一覧に戻れば OK
- 参考：書き方の見本「ページの移動」

### ステップ 7：見た目を整える

「ボタンを 4 列に並べる。表示欄は大きめの文字で、右寄せにする」

- 電卓らしい見た目になれば OK
- 参考：書き方の見本「CSS」
