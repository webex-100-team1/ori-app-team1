# マイページの続き

ファイル：`src/pages/mypage/MyPage.jsx`
ブランチ：`mypage-fix`

## 作るもの

1 周目のマイページ（PR #3）は画面は出るが、Firestore から実績を読めるかどうかをまだ確かめていない。データを入れて、`docs/tasks/mypage.md` の確認（ステップ 2〜5）を最後まで通す。あわせて、いらないコードを消す。

- 自分の実績が、新しい順に、名前と開放日時で並ぶ
- 実績がないときは「まだ実績がありません」と出る
- 見出しは「〇〇 さんのマイページ」の 1 つだけ

使うデータ：

| コレクション | フィールド |
| --- | --- |
| `achievements` | `uid`・`userName`・`name`（実績の名前）・`createdAt` |

始める前に：Firestore のセキュリティルールが設定されていないと、読むときに `Missing or insufficient permissions` のエラーになる。ルールはあさひが設定するので、終わったと聞いてから始める。

## 手順

### ステップ 1：見出しを 1 つにする

「`<h1>マイページ</h1>` を消して、名前の見出しを『〇〇 さんのマイページ』の 1 つにする」

- 画面の一番上に「〇〇 さんのマイページ」とだけ出れば OK

### ステップ 2：いらない `if` を消す

「`return (` の前にある `if (props.user === null || props.user === undefined)` の 3 行を消す」

「`useEffect` の中の `if` を消して、`getAchievements();` だけにする」

ログインしていない人は `App.jsx` でログイン画面に止められるので、マイページに `user` が無いまま来ることはない。

- マイページがこれまでどおり表示されれば OK

### ステップ 3：確かめ用の実績を手で入れる

Firebase のコンソールで、`achievements` コレクションにドキュメントを 1 件足す。フィールドは次のとおり。

| フィールド | 型 | 値 |
| --- | --- | --- |
| `uid` | string | 自分の UID（コンソールの Authentication の画面でコピーする） |
| `userName` | string | 自分の名前 |
| `name` | string | `ふるえる数字` |
| `createdAt` | number | `1763450000000` |

- コンソールの `achievements` に 1 件入っていれば OK

### ステップ 4：インデックスを作る

マイページを開くと、ブラウザのコンソールに「インデックスが必要」というエラーが出る。エラーの中のリンクを開いて「インデックスを作成」を押し、数分待つ。

- インデックスができてから再読み込みすると、エラーが消えれば OK

### ステップ 5：実績が並ぶのを確かめる

- ステップ 3 で入れた「ふるえる数字」が、開放日時と一緒に出れば OK
- コンソールでもう 1 件（`name` は `777`、`createdAt` は `1763460000000`）足して再読み込みすると、`777` が上に出れば OK

### ステップ 6：実績がないときを確かめる

- コンソールで自分の実績を全部消して再読み込みすると、「まだ実績がありません」と出れば OK
